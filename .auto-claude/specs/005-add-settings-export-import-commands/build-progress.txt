## Patterns to Follow
- Use existing _read_json/_write_json for file I/O
- Follow handle_command() routing pattern
- Use console.print() for user feedback
- Use dataclasses.asdict() for KaiSettings serialization

## Design Decisions
- Session-specific fields (last_session, agents) NOT exported/imported
- Import merges with existing settings (doesn't clobber)
- Support both snake_case and camelCase keys
- Default export filename: kai-settings.json
- Default import target: project (.kai/settings.json)
